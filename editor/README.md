# editor — редактор карт

Рисование местности **вектором**: контур леса, линия дороги с настоящей шириной, дом
прямоугольником, переправа точкой. Из фигур собираются поля свойств, которые читает бой, и граф
дорог — тем же кодом, что и в `vectormap.py`, так что редактор и генератор дают одинаковый
результат.

```bash
py -3.12 editor/map_editor.py                  # стартовый экран
py -3.12 editor/map_editor.py battle_3         # сразу открыть maps/battle_3.vector.json
```

Команды даны в проектной версии, но редактору хватает любого Python 3.9+ с `numpy`, `Pillow` и
`tkinter`. Запускать из КОРНЯ проекта.

## Файлы

| файл | что |
|---|---|
| `map_editor.py` | приложение: холст, инструменты, точки, сохранение |
| `project.py` | параметры проекта — масштаб, арена, состав сторон, палитра |
| `measure.py` | мерка карты (видимость, доли, вердикт годности) |
| `check_gui.py` | дымовой прогон всего пути без открытия окна |
| `check_measure.py` | контроль мерки на отобранном пуле |

## Работа

Холста при запуске нет. Три пути: **создать пустую** (размер задаётся явно, кнопка «под арену»
ставит 2550 × 2550 м), **сгенерировать** (скелет из `mapgen.py` — река, дороги, сёла, лес, дальше
правишь руками) или **открыть** готовую из списка.

**Рисование.** Инструменты: полигон, линия, дом, переправа, выбор/перенос, правка узлов, точка.
Полигон и линия набираются щелчками, заканчиваются двойным щелчком, ПКМ или Enter, отменяются
Esc. Дом ставится протяжкой: длина задаёт размер, направление — поворот вдоль улицы. Ширина
линии задаётся в метрах и запоминается по типу (дорога 8 м, река 30, лесополоса 25).

**Правка.** Выбор щелчком, перенос мышью, узлы двигаются и удаляются (ПКМ), Del удаляет фигуру,
Ctrl+Z / Ctrl+Y. Зеркалирование по Y — та же операция, которой `test_mirror.py` проверяет
симметрию среды: нарисовал половину, отразил, и разница в исходе боя точно не от карты.

**Сетка под фигурами.** Включённый показ полей рисует то, что реально достанется бою. Смотреть
на неё стоит постоянно: именно там видно, что дорога легла в одну клетку, а лесополоса в 20 м
не перекрыла обзор. Прозрачность сетки регулируется.

**Вид.** Колесо — зум к курсору, средняя кнопка или пробел — тащить, ползунок и кнопки ↺/↻ —
поворот на любой угол.

**Подложки.** Снимки под картой для обводки: прозрачность, поворот, масштаб, перетаскивание.
В вектор карты не попадают.

**Точки.** Объекты захвата и позиции сторон: ЛКМ — поставить или перетащить, ПКМ — убрать.
Позиций на сторону ровно столько, сколько слотов в составе из `units.json`. Кнопка «сохранить
сценарий» пишет `scenarios/*.json` форматом `scenario.py` — координаты в игровых единицах
`0..ARENA`. Сами точки хранятся в векторе карты и переживают закрытие.

**Замер.** Доли типов, строения, **видимость на 300–900 м** настоящим `terrain.blocked()`, и
вердикт годна / вырождена по фильтру пула.

**Сохранение** пишет `maps/<имя>.vector.json` и тут же собирает `<имя>.fields.npz` и
`<имя>.map.json` — карта сразу готова к бою. Вектор — единственное незаменимое: поля и граф
пересобираются под любой размер клетки одной командой.

Старые растровые карты (`maps/*.npy`) остаются играбельными, но не редактируются: у них нет
источника, только результат.

## Проверки

```bash
py -3.12 editor/check_gui.py        # весь путь: рисование → правка → точки → сборка → сценарий
py -3.12 editor/check_measure.py    # мерка против отбора пула
```

`check_gui.py` проходит путь без mainloop и проверяет то, где легко ошибиться: обратимость
экран↔мир при повёрнутом виде, зум без увода точки из-под курсора, ось Y (низ экрана — малый Y,
свои внизу поля), попадание всех нарисованных типов в сетку, лимит позиций по составу, чтение
вектора обратно и прохождение сценария через `scenario.validate()`.

`check_measure.py` — контроль мерки. Все 17 карт пула попадают в окно 25–85 % (27–81 %, медиана
61 %), обе карты сплошного леса отсеиваются (7 %), расходится одна: `platoon_crop_8` даёт 29 %
против 22 % в исходном отборе. Мерка — реализация критерия из `docs/JOURNAL.md`, а не тот самый
код: для «годна/вырождена» её хватает, для сравнения с числами журнала — нет.
