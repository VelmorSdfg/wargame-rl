# Архив документов

Написаны на ранних этапах и **описывают состояние, которого больше нет**: ротный масштаб,
поле 1500 м, точки-объекты вместо задачи, прежняя модель огня. Оставлены как история решений,
а не как справка — актуальное состояние целиком в [docs/JOURNAL.md](../JOURNAL.md).

- `COMMAND_ARCHITECTURE.md` — граница между RL и правилами. Сама граница осталась той же,
  но уровень сместился с роты на взвод.
- `HANDOFF.md` — брифинг для передачи в новый чат. Полностью заменён журналом.
- `ROADMAP.md` — иерархия от тактического ядра к полноценному варгейму. Направление в силе,
  сроки и порядок устарели.
- `WARGAME_MECHANICS.md` — справочник по механикам Eugen (Wargame RD / WARNO) и тому, как их
  переносить. **Не устарел**: это внешняя справка, а не описание нашего состояния.
