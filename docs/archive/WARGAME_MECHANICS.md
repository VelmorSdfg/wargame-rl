# Механики варгейма (Eugen: Wargame RD / WARNO) → наше ядро

Справочник при реализации «полноценного» ядра. Для каждой механики: **как сделано у Eugen**
и **как портировать в `WarGameEnv`**. В конце — рекомендуемая инженерная архитектура и порядок сборки.
Источники — в самом низу.

---

## 0. Философия, которую стоит забрать

- **Смертельность = маленькие HP + вычитательное пробитие.** Именно это даёт Red Dragon его
  «влепил — удалил». У нас сейчас пороги ×0.25 на больших HP — стоит перейти на схему Eugen.
- **Глубина = LOS + местность + мораль-с-бегством.** Не новые юниты, а эти три слоя превращают
  «кто кого перестреляет» в тактику.
- **Один бросок точности в момент выстрела** — попадание предопределено. Просто и детерминируемо.

---

## 1. Урон / броня / пробитие
**Eugen:**
- Цель с 0 брони → урон = `2 × AP`. Цель с бронёй ≥1 → урон = `((AP − Armor) / 2) + 1`.
- Пулы HP маленькие (единицы) → пробил/не пробил почти бинарно.
- **KE (кинетика):** пробитие растёт с приближением (~+1 за ~100 м). **HEAT:** постоянно на любой
  дистанции, всегда ≥1 урона, при перекрытии брони >10 добавляет урон → лучше по тяжёлой броне.
- **Криты:** шанс вывести подсистему (оптика/двигатель/топливо).

**Наше ядро:**
- Заменить `dmg·mult` на: `hp -= 0 if pen<armor else ((pen-armor)//2)+1` (KE), `heat` — своя ветка.
- Ввести `hp` в единицах (танк ~10, пехота ~10–15, ПТУР ~4).
- Range-scaling: `eff_pen = pen + k*(1 - dist/rng)` для кинетики; HEAT без скейла.
- Криты — опционально, позже (флаги `optics_hit`/`engine_hit`).

## 2. Точность
**Eugen:** один бросок при выстреле. Факторы: ветеранство, дистанция, aim_time, мораль, укрытие, ECM.
Движение снижает точность; лес даёт штраф атакующему. ECM вычитается из to-hit.

**Наше ядро (сейчас: дистанция + suppr):**
- `aim_time`: задержка первого выстрела после смены цели (счётчик, как `reload`).
- Штраф за движение: `acc *= 0.6`, если юнит двигался в этот тик.
- Ветеранство: `acc *= vet_mult[vet]`.
- Укрытие цели: `acc *= (1 - cover_aim_penalty)`.
- (ECM — когда появится авиация/ПВО.)

## 3. Подавление / мораль / сплочённость
**Eugen:** каждый выстрел даёт стресс на цель и по площади; бомба — большое поле, пуля — крохотное.
**Броня поглощает стресс: 1 armor = −5%.** Состояния RD: Calm→Worried→Shocked→Panicked→Stunned;
WARNO: Cohesion High/Normal/Poor/Low. Эффекты: ↓точность, ↑время прицела/перезарядки, ↑мор. урон, паника/бегство.

**Наше ядро (`suppr` уже есть):**
- Поглощение бронёй: `add_suppr *= (1 - 0.05*armor)`.
- Площадное подавление: у арты/взрывов стресс по радиусу, а не только по цели.
- Дискретные состояния морали → множители; при перегрузе — **автоматический откат назад (rout)**
  и `rally` со временем.

## 4. Оптика / стелс / LOS / разведка
**Eugen:** оптика = дальность/качество обнаружения; стелс = как близко надо подойти. Стелс — «поле»,
отталкивающее чужую оптику. **LOS жёсткий: нет линии — не видишь вообще**, даже вплотную. Ветеранство +5% к ID.

**Наше ядро (это «туман войны», дорогой для RL):**
- `optics` и `stealth` на юнит; факт обнаружения: `dist < optics - stealth` **И** есть LOS.
- LOS-рейкаст по сетке (см. §12). Необнаруженные враги скрыты из наблюдения.
- Для человека реализуется просто; тяжело именно RL-обучение под частичной видимостью (нужна память/`RecurrentPPO`).

## 5. Местность и укрытия
**Eugen:** лес — лучшее сокрытие (вертолёт не садится), болото (садится), изгородь — слабее. Укрытие =
защита + штраф атакующему. Пехота в лесу/зданиях очень сильна. Открытое поле — виден всем.

**Наше ядро (Фаза A ландшафта, на текущей архитектуре):**
- Сетка тайлов с типами; производные слои: `cover`, `passable`, `blocks_los`, `height`.
- `cover` → множитель урона и штраф acc атакующему; `passable` → скорость в `_move`; `height` → бонус rng/LOS.
- Здания — особые тайлы: пехота «в гарнизоне» получает большой cover, но уязвима к арте/обходу.

## 6. Артиллерия / непрямой огонь
**Eugen:** дисперсия (меньше = точнее; длинный ствол точнее) + aim_time. Разведка даёт «наблюдение» —
резкий буст точности в радиусе ~2 км. Салвы очередью, авто-перенос. Жрёт огромный запас снабжения.

**Наше ядро (новый тип):**
- Приказ = точка на карте; снаряд падает с гауссовым разбросом вокруг (радиус = `dispersion`).
- Задержка полёта + `aim_time`; AoE-урон и подавление по радиусу.
- Наблюдатель (разведюнит рядом с целью) снижает `dispersion`.
- Расход `ammo` большой → завязка на снабжение (§8).

## 7. Ветеранство (5 уровней: Rookie→Trained→Hardened→Veteran→Elite)
**Eugen:** главный бонус — точность (стоя и в движении; у элиты ~+50% против номинала). Быстрее прицел,
сильнее сопротивление морали, быстрее выход из стана (−19%), быстрее восстановление морали (+150%),
арта — меньше дисперсии (−10%). **НЕ влияет** на HP/броню/скорость.

**Наше ядро:** один скаляр `vet` на юнит → таблица множителей к `acc`, `aim_time`, `sr` (supp-resist), `dispersion`.

## 8. Снабжение / боезапас
**Eugen:** конечный боезапас; пополнение через грузовики/FOB; арта — прожорливейший потребитель.

**Наше ядро:** `ammo` на юнит (особенно ПТУР ~4, арта ~несколько салв); юнит-снабженец пополняет в радиусе.

## 9. Авиация (самолёты и вертолёты)
**Eugen:** самолёты живут на аэродроме, 3 статуса (готов / на задании / пополнение). Кончились топливо/ammo
→ авто-возврат («evac bingo»). Бомбер по клавише T бьёт по точке **даже без видимости** цели. ПВО: ИК —
стреляет в движении, близко, много ammo; радарные — дальше всех, мало ammo, всегда цель для SEAD. Вертолёты
легко выкашиваются ствольным ПВО. Скаут-вертолёты с хорошей оптикой = разведка.

**Наше ядро:**
- Флаг `is_air`: летит над картой (игнор `passable`), заходит на ограниченное время + `ammo`, потом уходит
  на пополнение (таймер «вне карты»). Не постоянно на поле — «пролёт».
- ПВО — юнит с приоритетом по воздуху: большой `rng` (радар) либо мобильность/стрельба-в-движении (ИК).
- Вертолёты — как наземные, но `is_air` и очень уязвимы к ПВО (высокий `sg` от AA).

## 10. Транспорт пехоты (посадка/высадка)
**Eugen:** вся пехота приезжает в транспорте; выбор **APC** (дёшево, спам) vs **IFV** (дорого, автопушка).
Транспорт = скорость + защита: под напалмом/бомбами загрузка обратно в IFV спасает. Разные шасси
(гусеницы/колёса/вертолёт) под разные задачи. Возить технику с экипажем нельзя (баланс).

**Наше ядро:**
- Связь «пехота ↔ транспорт»: состояние `mounted` (пехота скрыта внутри, едет со скоростью транспорта,
  не стреляет), `dismount` по приказу.
- Транспорт уничтожен с десантом внутри → урон/принудительная высадка пехоты.
- Реализуется как пара `carrier_id` + флаг — дёшево.

## 11. Командиры и контроль секторов (CV)
**Eugen:** командная техника «капит» сектор **присутствием** (стоя); контролируемая зона даёт очки
подкреплений, точки развёртывания и воздушные коридоры. Без живого CV **нельзя вызывать подкрепления**.
Зона контестится, если оба CV внутри. Защита CV критична.

**Наше ядро:**
- Флаг `is_command`; карта делится на секторы; сектор захвачен, если в нём стоит твой CV и нет чужого →
  капает бюджет очков (§8/подкрепления) и открывает спавн.
- Даёт **условие победы по очкам/зонам**, а не только по уничтожению. Простая привязка «сектор → владелец
  по присутствию CV».

## 12. Рекомендуемая инженерная архитектура

**Принцип: ядро — чистая детерминированная headless-симуляция. Всё висит на трёх опорах.**

### Опора 1. Контент как данные (SoA + JSON)
- Юниты/оружие/местность — во внешних JSON, не в коде. Юнит может иметь **список оружий**.
- Состояние — параллельные numpy-массивы (structure-of-arrays): `pos`, `hp`, `suppr`, `reload`, `vet`, …
  Быстро для сотен юнитов и удобно для RL. Новый юнит = строка данных, а не правка кода.

### Опора 2. Карта и LOS
- Карта — 2D numpy-сетка `terrain_id` + производные слои (`cover`, `passable`, `blocks_los`, `height`).
- **LOS/LOF — рейкаст по сетке** (Bresenham/DDA): идём по клеткам отрезка стрелок→цель, если встретили
  `blocks_los` (с учётом height) — линия перекрыта. Считать только для нужных пар (ближайшие кандидаты),
  не N².

### Опора 3. Слой приказов (команда → намерение)
- У юнита стойкий **приказ**: `move_to(point)`, стойка (`hold` / `attack_move` / `hunt` / `fast`).
- Каждый тик приказ разворачивается в низкоуровневое намерение (вектор движения, можно ли открывать огонь).
- **Развязывает источник управления:** человек / скрипт / RL дают одинаковые приказы. Тот же слой — вход для RL высокого уровня.

### Тик-конвейер (фиксированный порядок, один seeded-RNG)
```
1. Приказы    → намерения движения
2. Движение   (× passable, × suppr, × vet)
3. Обновление обнаружения (optics/stealth + LOS)
4. Выбор целей (в радиусе, есть LOF, приоритет типов)
5. Разрешение огня: бросок acc (дист, движение, aim_time, мораль, cover, vet) → пробитие → урон
6. Применить урон + подавление (поглощение бронёй, AoE)
7. Мораль: состояния, откат/бегство, rally; расход ammo, снабжение
8. Смерти, условия победы
```
Детерминизм (единый RNG, seed) обязателен — нужен для воспроизводимости, реплеев и RL.

### Технологии
- **Оставаться на Python/numpy** для ядра: при векторизации тянет сотни юнитов, и RL-интеграция бесплатна.
- Если однажды понадобятся тысячи юнитов в реалтайме — вынести горячие циклы в `numba`/C. **Сейчас рано.**
- Рендер (pygame) и ИИ — **строго отдельные модули** за интерфейсом ядра. Ядро о них не знает.

### Порядок сборки (каждый слой играбелен)
1. **Фундамент:** данные (JSON) + карта/LOS + слой приказов + `play_human`.
2. **Смертельность:** переписать урон на «мало HP + вычитание» (§1).
3. **Глубина боя:** ammo, мульти-оружие + приоритет целей, штраф за движение, ветеранство, мораль/бегство.
4. **Состав сил:** разведка, ПВО, артиллерия (после карты), авиация, транспорт.
5. **Стратегия:** туман войны (после LOS), C2/HQ, очки/подкрепления, зоны захвата.
